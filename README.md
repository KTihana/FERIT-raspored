# FERIT raspored

Your FERIT timetable on your phone.

[Vodič sa slikama — korištenje aplikacije](docs/guide.md)

## Install on Android

[Download APK — version 1.0.9](https://github.com/KTihana/FERIT-raspored/releases/download/v1.0.9-android-test/FERIT-raspored.apk) · Android 7.0+

Open the downloaded file and install it. Install over the previous app to keep your saved choices. The app runs locally; internet is needed for FERIT timetable data and update checks.

## Updates

When **Dostupno ažuriranje** appears, tap **Preuzmi** and confirm installation on Android. Manual check: **Postavke → Ažuriranja aplikacije → Provjeri ažuriranja**.

Restore the original timetable: **Postavke → Vrati izvorni raspored**.

[Source project](https://github.com/KTihana/FERIT-raspored/releases/download/v1.0.9-android-test/FERIT-raspored-source.zip) · iPhone installation requires Xcode and Apple signing.
